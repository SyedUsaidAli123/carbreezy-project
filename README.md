# CarBreezy Pakistan

Pakistan's trusted car marketplace for buying and selling cars.

---

## About

CarBreezy is a responsive car marketplace website built as an Aptech 1st Semester eProject.

---

## Features

- Responsive Design
- 10 Pages
- 14 Cars (New + Used)
- Filter System (Hatchback, Sedan, SUV, Convertible)
- Sort Functionality (Price, Name)
- Car Detail Popup with 4 Tabs
- 8 Brands with Dynamic Count
- Offers with Countdown Timer
- Gallery with Lightbox
- FAQ Accordion
- Google Maps Integration
- Visitor Counter
- Live Ticker (Date, Time, Location)

## How to Run

1. Clone the repository
2. Open in VS Code
3. Install Live Server extension
4. Right-click on index.html
5. Click "Open with Live Server"
